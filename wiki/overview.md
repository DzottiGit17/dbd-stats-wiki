# Overview

This vault is the knowledge base behind a **Dead by Daylight stats & trivia website**.

## What we're building content for
1. **Most used characters** — killer and survivor pick-rate rankings
2. **Most used perks per character** — perk pick-rate rankings, split by killer perks and survivor perks
3. **Trivia** — fun/notable stats (most-killed survivor, most-picked killer, rarest perk usage, etc.)
4. **Best combo perks** — proven strong perk synergies
5. **Fun builds** — creative/meme builds worth featuring, not just meta

## How the vault maps to that

| Folder | Contains |
|---|---|
| `wiki/killers/` | One page per killer: overview, common perks used, playstyle notes |
| `wiki/survivors/` | One page per survivor: overview, common perks used |
| `wiki/perks/` | One page per perk: effect, which side, usage rate, synergy notes |
| `wiki/builds/` | Named builds (meta and fun), perk combos, why they work |
| `wiki/trivia/` | Standalone stat/fact pages: records, rankings, "did you know" |
| `wiki/site/` | Drafts/outlines of actual website pages, pulling from the above |
