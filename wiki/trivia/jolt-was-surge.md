# Jolt Used to Be Surge

Jolt is currently one of the most-used killer perks in the game (22% pick rate as of the 7.1.0 stats window). Before it was Jolt, it was **Surge** — a unique perk belonging to **The Demogorgon**, the licensed Stranger Things killer.

When Netflix's Stranger Things license lapsed, BHVR pulled The Demogorgon (and Nancy Wheeler/Steve Harrington) from the game entirely. Rather than delete Surge along with the killer, BHVR renamed it Jolt and made it a general perk any killer can use — which is part of why it's so widely picked today: everyone has access to it.
